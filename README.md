## 📋 Estructura y Sílabo del Curso

Este repositorio contiene las soluciones computacionales, ejercicios prácticos, código y proyectos integradores desarrollados durante el curso **Lenguajes de Programación II (EP3035)** de la UNALM, organizado en dos bloques evaluativos principales.

---

### 📑 Parte 1: Examen Parcial (Unidades 1 a 5)

Consolidado integral de los fundamentos de entornos de trabajo, algoritmos, paradigmas de programación, automatización en terminal y control de versiones:

- [x] **1. Entorno Jupyter & Generación de Reportes**
  - Configuración y automatización de reportes computacionales en Jupyter Notebooks.
  - Documentación técnica estructurada mediante sintaxis Markdown y fórmulas estadísticas en LaTeX.
- [x] **2. Estructuras de Datos Avanzadas**
  - Implementación y manipulación eficiente de estructuras lineales y no lineales en Python:
    - Listas enlazadas (simples y dobles), Pilas (LIFO), Colas (FIFO) y Árboles de decisión/búsqueda.
- [x] **3. Programación Orientada a Objetos (POO)**
  - Diseño modular y arquitectura limpia aplicada al desarrollo de software:
    - Clases, Objetos e Instancias Múltiples.
    - Aplicación de principios POO: Abstracción, Encapsulamiento, Herencia y Polimorfismo.
- [x] **4. Scripting y Automatización en Bash/Shell**
  - Automatización de tareas de sistema e interactividad en entornos Unix/Linux:
    - Scripts en Bash, variables de entorno, estructuras de control de flujo (`if`, `for`, `while`) y procesamiento de argumentos por línea de comandos.
- [x] **5. Control de Versiones con Git & GitHub**
  - Control de cambios y flujos de trabajo colaborativos en desarrollo de software:
    - Manejo de repositorios locales y remotos (`commit`, `branch`, `merge`, `rebase`, `pull request`).

---

### 📑 Parte 2: Examen Final (Unidades 6 a 8 + Proyecto Final)

Desarrollos enfocados en extracción, manipulación e integración de datos distribuidos en la web:

- [ ] **1. Expresiones Regulares (Regex)**
  - Construcción de patrones avanzados para búsqueda, validación de formatos, filtrado de texto y extracción de información no estructurada.
- [ ] **2. Programación en Red & Web Scraping**
  - Comunicación mediante Sockets y protocolo HTTP.
  - Extracción y parseo automatizado de datos cualitativos y cuantitativos desde páginas web utilizando bibliotecas como BeautifulSoup y Requests.
- [ ] **3. Integración con Web Services & APIs**
  - Consumo e ingesta de APIs RESTful.
  - Procesamiento y serialización de datos estructurados e semiestructurados en formatos XML y JSON.
- [ ] **4. Proyecto Final Integrador**
  - Desarrollo de un sistema de software integrador que aplica el pensamiento computacional para la extracción, modelado y procesamiento de datos.
